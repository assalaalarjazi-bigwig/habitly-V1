# Habitly (تطبيق هابتلي لتتبع العادات)

> تطبيق جميل، هادئ، وخفيف لتتبع العادات اليومية بمبدأ **أوفلاين أولاً (Offline-First)** وتصميم عصري مريح. يدعم اللغتين العربية والإنجليزية بشكل كامل مع اتجاه RTL/LTR، ويحتوي على نظام سلاسل الإنجاز (Streaks)، تقويم شهري، إحصائيات، ونظام أوسمة وإنجازات. التطبيق مجهز بالكامل بنظام **Capacitor Android** للبناء المباشر كملف **APK** عبر **GitHub Actions** دون الحاجة إلى Expo ودون تثبيت Android Studio على جهازك.

---

## 🚀 كيفية رفع التطبيق على GitHub وتحميل ملف APK مباشرة (بدون Expo وبدون أي أدوات خارجية)

المشروع الآن يحتوي على مشروع أندرويد أصلي مدمج (`android/`) مع إعدادات البناء التلقائي عبر **GitHub Actions**. لا تحتاج إلى إنشاء أي حسابات خارجية (لا حاجة لـ Expo إطلاقاً)، ولا تحتاج إلى إضافة أي رموز سرية (Secrets). بمجرد رفع الكود، سيقوم خادم GitHub نفسه بتجميع الكود وبناء ملف الـ APK!

---

### 📋 الخطوة 1: رفع المشروع من جهازك إلى GitHub
افتح موجه الأوامر (Terminal أو Git Bash) داخل مجلد المشروع، ثم نفّذ الأوامر التالية بالترتيب:

```bash
# 1. تهيئة مستودع Git محلي
git init

# 2. إضافة كافة ملفات المشروع
git add .

# 3. حفظ التغييرات
git commit -m "feat: complete Habitly app with direct Android APK workflow"

# 4. جعل اسم الفرع الرئيسي main
git branch -M main

# 5. ربط المستودع بمستودعك الجديد على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/USERNAME/habitly.git

# 6. رفع الملفات إلى GitHub
git push -u origin main
```

*(ملاحظة: استبدل `https://github.com/USERNAME/habitly.git` برابط مستودعك الذي أنشأته على GitHub).*

---

### ⚡ الخطوة 2: تشغيل البناء وبدء إنشاء ملف الـ APK
ملف الأكشن مبرمج مسبقاً في مسار `.github/workflows/build-apk.yml`. سيبدأ العمل تلقائياً بمجرد رفع الكود، أو يمكنك تشغيله يدوياً في أي وقت كالتالي:

1. افتح صفحة مستودعك على **GitHub**.
2. اضغط على تبويب **Actions** في الشريط العلوي للمستودع.
3. ستجد في القائمة الجانبية اليسرى سير عمل باسم: **Build Android Standalone APK**.
4. اضغط عليه، ثم اضغط على زر **Run workflow** الموجود في الجهة اليمنى.
5. اختر الفرع `main` ثم اضغط على الزر الأخضر **Run workflow**.

---

### 📥 الخطوة 3: تحميل وتثبيت ملف الـ APK
1. سيقوم خادم GitHub (Ubuntu) بتشغيل بيئة الأندرويد وأداة Gradle تلقائياً وبناء ملف التطبيق (تستغرق العملية حوالي 3 إلى 5 دقائق).
2. عند انتهاء البناء وظهور علامة الصح الخضراء ✅، اضغط على اسم البناء للدخول إلى صفحة تفاصيل المهمة (**Summary**).
3. انزل لأسفل الصفحة حتى تصل إلى قسم **Artifacts** (المرفقات).
4. ستجد ملفاً جاهزاً باسم:
   ```text
   Habitly-Android-APK
   ```
5. اضغط عليه لتحميله كملف مضغوط (`.zip`).
6. فك الضغط عن الملف وستجد بداخله ملف التثبيت المباشر `app-debug.apk`.
7. أرسل الملف إلى هاتفك الأندرويد وثبته كأي تطبيق عادي فوراً واستمتع بالتطبيق!

---

### 💡 لماذا هذه الطريقة هي الأفضل والأسهل؟
- **بدون أي خدمات خارجية**: لا حاجة لتسجيل حساب على Expo أو أي منصة طرف ثالث.
- **بدون مفاتيح سرية (Zero Secrets)**: لا تحتاج لإعداد أي Tokens أو Secrets في إعدادات GitHub.
- **تطبيق أندرويد حقيقي وأصيل (Native Android)**: ملفات تطبيق الأندرويد جاهزة وموجودة في مجلد `android/` ويتم بناؤها باستخدام أداة Google الرسمية (Gradle).
- **أوفلاين بنسبة 100%**: كل ملفات واجهة الويب وملفات الصوت والترجمة مضمنة بالكامل داخل حزمة الـ APK وتعمل فور تثبيتها دون أي اتصال بالإنترنت.

---

## 🌟 مميزات تطبيق Habitly

- **100% بدون إنترنت (Offline-First)**: خصوصية كاملة على الهاتف المحلي بدون أي قواعد بيانات سحابية.
- **دعم ثنائي اللغة (عربي / إنجليزي)**:
  - **العربية لغة افتراضية** مع دعم كامل لاتجاه الواجهة من اليمين إلى اليسار (RTL).
  - إمكانية التبديل إلى الإنجليزية (LTR) مع ترجمة فورية شاملة لكل النصوص والعادات.
- **سلاسل الإنجاز (Streaks)**: متابعة دقيقة لسلسلة الأيام المتتالية وأفضل إنجاز قياسي.
- **تقويم شهري تفاعلي**: استعراض ومراجعة إنجاز كل يوم على حدة وإمكانية تعديل السجل.
- **نظام أوسمة وإنجازات**: محفزات إيجابية مع أصوات تفاعلية هادئة وخفيفة.
- **مظهر وثيمات مخصصة**: تبديل بين الوضع الفاتح، الداكن، والتلقائي مع 6 سمات ألوان منتقاة بعناية، وزر صريح لحفظ الإعدادات.
